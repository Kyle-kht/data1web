# 📱 导购员业绩管理系统 - 部署指南

## 🚀 5分钟快速部署

### 方法一：Netlify Drop（最简单）
1. 访问：https://app.netlify.com/drop
2. 把整个文件夹拖进去
3. 完成！获得链接

### 方法二：Vercel
1. 代码上传 GitHub
2. 用 GitHub 登录 Vercel
3. 一键部署

### 方法三：GitHub Pages
1. 创建 GitHub 仓库
2. 上传 index.html
3. 仓库设置 → Pages → 选择分支 → 保存

如需云数据库，请配置 Supabase。
